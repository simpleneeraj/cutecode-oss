CuteUI is the component set behind the CuteCode apps. The parts are built on Base UI, so keyboard and screen reader support comes from the base, then styled with Tailwind and design tokens.

## What is in it

- **Base UI primitives.** Dialogs, menus, selects, tabs and more.
- **Solar icons.** One icon family across every part.
- **Apple HIG.** Sizes, spacing, touch targets and motion follow the Apple Human Interface Guidelines.
- **Styles.** Change the look of the whole set from one token layer.
- **Palettes.** Swap the accent color without touching a component.
- **Font pairings.** Choose a heading and body font that fit together.
