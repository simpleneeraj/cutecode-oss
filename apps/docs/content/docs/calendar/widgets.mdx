## Import

```tsx
import { SmallWidget } from "@cutecode/calendar/widgets/small";
import { MediumWidget } from "@cutecode/calendar/widgets/medium";
import { MediumNotchWidget } from "@cutecode/calendar/widgets/medium-notch";
import { LargeWidget } from "@cutecode/calendar/widgets/large";
```

## Props

| Prop | Type | Notes |
|---|---|---|
| `data` | `CalendarData` | Events and calendars. |
| `options` | `WidgetOptions` | Locale, zone, week start, pinned now. |
| `placeholder` | `boolean` | Optional. Shows quiet placeholder lines. |

## States

- Small: today.
- Medium: date tile with the next two events.
- Medium with notch: a folder tab holds the time of the next event.
- Large: month glance and three events.
- Each has a day done, a placeholder and a busy day.
